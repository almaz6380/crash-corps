# Crash Corps

Browser-Prototyp eines klassenbasierten Cartoon-Arena-Shooters (Three.js). Siehe `CLAUDE.md` für Architektur und Roadmap.

```
npm install
npm run dev
```

Steuerung: Klick ins Spiel = Maus fangen, WASD laufen, Shift sprinten, Leertaste springen, Linksklick schießen, R nachladen, Q Spezialfähigkeit, Esc Menü.
